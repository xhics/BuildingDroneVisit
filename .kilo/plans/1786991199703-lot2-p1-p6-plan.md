# Plan: Lot 2 — Reconstruction Pipeline (P1-P6)

## Goal

Construire le pipeline de reconstruction Lot 2 **par-dessus** Lot 1B sans le modifier. Lot 1B reste la source de vérité pour les preuves, le Router, les digests et le paquet proxy. Lot 2 consomme ses artefacts via `ReconstructionInputManifest`.

## Principes directeurs

1. **Lot 1B intact** : ses manifestes, Router, digests, traçabilité et paquet proxy ne sont pas modifiés.
2. **Deux routers séparés** : le Router Lot 1B répond à « quelles preuves/matières ? » ; `ReconstructionPlan` répond à « quel solveur ? ».
3. **Apparence ≠ Géométrie** : `appearance_union_fraction` vs `geometric_support_fraction` ne sont jamais fusionnées.
4. **Pas d'écrasement silencieux** : `scene_package_type` distingue `hybrid_proxy` vs `reconstructed_*`.
5. **Droits = provenance, pas gate** : les droits sont tracés mais n'excluent pas des images de la reconstruction.
6. **Consensus avant engagement** : plusieurs backends tournent sur le même input ; le meilleur est choisi par métriques.

## P1 — View Graph (le vrai G5)

**Objectif :** Mesurer la continuité réelle du corpus avant d'exécuter un solveur coûteux.

### 1.1 Preprocessing + masks

**Fichier :** `src/hotel_pipeline/reconstruction_preprocess.py` (nouveau)

**Fonctions :**
- `generate_mask_set(workspace, input_manifest, mask_classes) → str` : génère des masques binaires pour `sky`, `people`, `cars`, `water`, `large_reflections`, `signage`, `mobile_furniture`
- `normalize_image(input_path, output_path) → None` : normalise exposure, white balance, resize, lens distortion
- Stocke les masques comme `DerivedArtifact` dans `05_colmap/preprocessed/masks/<asset_id>.png`
- Retourne `mask_set_digest` (SHA-256)

**CLI :** `hotel-pipeline reconstruction preprocess <hotel_id> --mask-class sky --mask-class people`

### 1.2 ViewGraphManifest

**Schéma :** `src/hotel_pipeline/schemas/reconstruction.py`

```python
class ViewGraphManifest(BaseModel):
    contract_version: int = 1
    view_graph_id: str
    reconstruction_input_id: str
    created_at: str
    nodes: list[ViewGraphNode]        # asset_id, intrinsics, pose_status, quality_score
    pairs: list[PairEvidence]         # image_a, image_b, retrieval_score, matches, inliers, inlier_ratio, relative_pose, overlap_estimate, degeneracy, status
    report: ViewGraphReport           # images_selected, pairs_tested, valid_pairs, largest_component, registered_candidate_ratio, median_inlier_ratio, continuity_by_demand, repetitive_risk, intrinsics_quality
```

**Fichier :** `src/hotel_pipeline/view_graph.py` (nouveau)

**Classes :**
- `ViewGraphBuilder` : construit le graphe de vue depuis `ReconstructionInputManifest`
  - `build(input_manifest) → ViewGraphManifest`
- `RetrievalStrategy` : candidates via `view_sector`, `viewpoint_cluster`, GPS < 50m, descripteur global ORB
- `MatchingStrategy` : SIFT+LightGlue (baseline), ALIKED+LightGlue (candidat)
- `GeometricVerification` : essential matrix, RANSAC, inlier_ratio

**Fonctions :**
- `_retrieval_candidates(input_manifest, workspace) → list[tuple[str, str, float]]`
- `_match_pair(asset_a, asset_b, workspace, matcher, max_features) → PairEvidence`
- `_haversine_m(lat1, lon1, lat2, lon2) → float`

**CLI :** `hotel-pipeline reconstruction view-graph <hotel_id>`

**Output :** `07_reconstruction/view_graphs/view_graph_<id>.json`
